# 文件封存區

> 狀態：冷封存  
> 最後更新：2026-08-27  
> 預設讀取：否

這裡保存已完成功能的歷史規格與階段性交接紀錄。內容只代表當時的需求、實作與決策背景，不是現行系統的權威來源。

## 讀取政策

- 一般開發、除錯、設計與文件工作不得主動搜尋或讀取本目錄。
- 只有使用者明確要求查詢歷史規格、交接紀錄或「當時為什麼這樣設計」時才調閱。
- 調閱時只開啟和問題直接相關的檔案，不批次載入整個封存區。
- 若封存內容與現行程式、測試、[`../architecture/`](../architecture/) 或 [`../design/`](../design/) 衝突，以現行來源為準。

## 分類

```text
archive/
├─ README.md                 # 封存政策與調閱入口
├─ specifications/          # 已完成或已被取代的功能規格
└─ handoffs/                # 特定日期或階段的交接快照
```

需要封存新文件時，請在文件頂部標示狀態與日期；完成搬移後，移除現行文件對它的日常閱讀連結。
