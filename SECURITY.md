# Security Policy

## Supported versions

Security fixes target the latest commit on `main`. Older commits, forks, and independently deployed
instances are not maintained by this repository owner.

## Reporting a vulnerability

Use [GitHub Private Vulnerability Reporting](https://github.com/Jwander0820/temp-storage/security/advisories/new)
to report a suspected vulnerability privately. Include the affected route or component, impact,
reproduction steps, and a minimal proof of concept when safe.

Do not put secrets, invitation URLs, delete tokens, working file URLs, personal data, or undisclosed
vulnerability details in a public issue. If private reporting is temporarily unavailable, open a public
issue that only asks the maintainer to provide a private contact channel; do not include sensitive
details.

The maintainer will acknowledge reports and share status as availability permits. Response and repair
times depend on severity and reproducibility; this project does not promise a fixed SLA.

## Scope

Reports about this source code and its documented default configuration are in scope. Abuse reports,
expired shared files, and problems unique to an independently operated fork should be handled by that
deployment's operator.
